# Settings

Open **Settings** from the command bar (or Ctrl/⌘ + ,).

![Settings dialog](../images/screenshots/settings-dialog.png)

| Setting | Options |
|---|---|
| **Language** | System default, English, Deutsch. Takes effect immediately, including menus and the view cube. |
| **Theme** | System, light, dark |
| **3D navigation** | Mouse or trackpad (see [navigation](navigation.md)) |
| **Projection** | Orthographic or perspective |
| **Show frame statistics** | Shows frames per second and render time in the status bar |

![Dark theme in German](../images/screenshots/dark-theme-german.png)

Settings are stored per user in `settings.json` in the application data folder
(`%APPDATA%/ParaWerk` on Windows, `~/Library/Application Support/ParaWerk` on macOS,
`~/.config/ParaWerk` on Linux). The window size and position are restored on the next start.
